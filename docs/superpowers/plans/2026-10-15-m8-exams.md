# M8 Exams Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The learner can take a short timed exam in their project. `:TutorExam small` writes a brief and runnable example tests into `exam/<id>/`. The widget shows a soft timer, and hints stay at rung 2 or lower. `:TutorSubmit` runs the tests, has the model grade the code against the brief with `file:line` evidence, writes `grade.md`, and records the score in the profile. `:TutorRun` reads the project's `run:` and `test:` commands from the README. Tasks in `spec/tasks.md` get ticked when the model says they are done and the next run passes. `:TutorProgress` shows trends from the profile.

**Architecture:** New pure modules live under `extensions/tutor/exam/`:
- `layout.ts`: per-language exam folders, test commands and broken-test detection;
- `make.ts`: exam-maker JSON, validation, brief, writing, test probe;
- `state.ts`: the exam session entry, timer label and context line;
- `grade.ts`: learner files, examiner JSON, score, `grade.md`.

Shared helpers:
- `files.ts`, a root-checked writer;
- `tasks.ts`, task ticking;
- `report.ts`, `/tutor-progress`.

`index.ts` wires the commands, the timer and the rung cap. The extension runs the exam tests itself through `pi.exec` (cwd = the exam folder); the model never runs anything. Neovim gets three thin commands, and `:TutorRun [run|test]` reads the README front matter.

**Tech Stack:** TypeScript (Node 26, `node:sqlite`), vitest, Pi 1.1.0 extension API, Lua/plenary, Markdown roles and skills.

**Spec:** `docs/superpowers/specs/2026-10-13-tutor-roles-packs-exams-design.md` §3 (exam roles), §6 (exams), §8 (files), §9 M8 row. The task-ticking and `:TutorRun` items come from `docs/superpowers/specs/2026-10-07-nvim-tutor-design.md` (`tasks.md` is the progress source; `:TutorRun` reads README front matter), which spec 2026-10-13 §9 moves into M8.

## Review Focus

1. **The model writes tests that do not compile or import.** An exam is never handed over broken: the probe run detects it, the files are removed, and the model is asked once more. Two failures give a clear error and leave no folder behind (Task 5 test with a broken Python test file).
2. **The learner's code hangs or loops forever at submit.** The test run is killed at 120 s. The grade says it timed out, and Pi is never stuck (Task 7 test with an exec that reports `killed`).
3. **Pi restarts, `/new` or `/resume` mid-exam.** The exam comes back from the session entry. The timer counts from the real start, and late is wall-clock (Task 6 test with a `started` an hour ago).
4. **The model's grade cites a file or line that does not exist, skips a requirement, or says everything passed while the tests failed.** Such a grade is rejected and retried, and nothing is written (Task 7 tests).
5. **Path safety and collisions.**
   - `exam/` is a symlink to a folder outside the project;
   - `exam/<id>` already exists;
   - `spec/tasks.md` is open with unsaved edits in Neovim.

   In each case the extension refuses or waits, and never overwrites or writes outside (Task 2 and Task 5 tests).

```lua
  local ok, lines = pcall(vim.fn.readfile, vim.fs.joinpath(dir, "README.md"), "", 40)
  if not ok or lines[1] ~= "---" then return {} end
  local fm = {}

    local k, v = lines[i]:match("^([%w_-]+):%s*(.-)%s*$")

end
```

```ts
import { existsSync, mkdirSync, realpathSync, writeFileSync } from "node:fs";
import { dirname, isAbsolute, join, normalize, sep } from "node:path";

// The one way the extension writes into a project (M8): exam files and spec/tasks.md.
// CLAUDE.md: every path is inside the root after realpath; a symlinked folder or file never leads out.
const inside = (real: string, root: string) => real === root || real.startsWith(root + sep);

/** The nearest existing ancestor of `p` (checked before any folder is made, so nothing is created outside). */
function nearestExisting(p: string): string {
  let d = p;
  while (!existsSync(d)) d = dirname(d);
  return d;
}

export function writeInRoot(root: string, rel: string, text: string, opts: { exclusive?: boolean } = {}): string {
  if (isAbsolute(rel) || normalize(rel).split(sep).includes("..")) throw new Error(`${rel} is not a path inside the project`);
  const realRoot = realpathSync(root);
  const abs = join(realRoot, normalize(rel));
  if (!inside(realpathSync(nearestExisting(dirname(abs))), realRoot)) throw new Error(`${rel} resolves outside the project`);
  mkdirSync(dirname(abs), { recursive: true });
  if (existsSync(abs) && !inside(realpathSync(abs), realRoot)) throw new Error(`${rel} resolves outside the project`);
  writeFileSync(abs, text, { flag: opts.exclusive ? "wx" : "w" });
  return abs;
}
```

`tasks.ts`:

```ts
import { findTask } from "./workflow.js";

// spec/tasks.md is the progress source (spec 2026-10-07): ticking turns "[ ]" into "[x]" on the
// task's own line. Pure; index.ts decides when (M8 D6: after a passing run).
export function tickTasks(md: string, ids: string[]): { text: string; ticked: string[]; missing: string[] } {
  const eol = md.includes("\r\n") ? "\r\n" : "\n";
  const lines = md.split(/\r?\n/);
  const ticked: string[] = [], missing: string[] = [];
  for (const id of ids) {
    const line = findTask(lines.filter((l) => /\[ \]/.test(l)).join("\n"), id);
    const i = line === null ? -1 : lines.indexOf(line);
    if (i < 0) { missing.push(id); continue; }
    lines[i] = lines[i].replace("[ ]", "[x]");
    ticked.push(id);
  }
  return { text: lines.join(eol), ticked, missing };
}
```

```ts
export type ExamSize = "small" | "medium";
export const LIMIT_MIN: Record<ExamSize, number> = { small: 20, medium: 45 };

export interface ExamSpec { title: string; task: string; requirements: { id: string; text: string }[]; examples: string; concepts: string[]; stub: string; tests: string }

export function parseExamArgs(args: string): { kind: "start"; size: ExamSize; topic: string | null } | { kind: "check" } | { kind: "off" } {
  const a = args.trim();
  if (a === "check" || a === "off") return { kind: a };
  const [first, ...rest] = a.split(/\s+/);
  const size: ExamSize = first === "medium" || first === "small" ? first : "small";
  const topic = (size === first ? rest.join(" ") : a).trim();
  return { kind: "start", size, topic: topic || null };
}

const text = (o: Record<string, unknown>, k: string): string => {
  const v = o[k];
  if (typeof v !== "string" || !v.trim()) throw new Error(`${k} must be a non-empty string`);
  return v;
};

export function checkExam(v: unknown, vocab: Vocab | null): ExamSpec {
  if (typeof v !== "object" || v === null) throw new Error("reply must be a JSON object");
  const o = v as Record<string, unknown>;
  const reqs = Array.isArray(o.requirements) ? o.requirements : [];
  if (reqs.length < 2 || reqs.length > 6) throw new Error("requirements must list 2 to 6 items");
  const requirements = reqs.map((r, i) => {
    const x = (r ?? {}) as Record<string, unknown>;
    if (x.id !== `R${i + 1}`) throw new Error(`requirement ids must be ${reqs.map((_, j) => `R${j + 1}`).join(", ")} in order`);
    return { id: x.id, text: text(x, "text") };
  });
  const tests = text(o, "tests");
  for (const r of requirements) {
    if (!new RegExp(`r${r.id.slice(1)}(?!\\d)`, "i").test(tests)) throw new Error(`no test for ${r.id}: name each test after its requirement`);
  }
  const concepts = normalizeTags(Array.isArray(o.concepts) ? o.concepts.filter((c): c is string => typeof c === "string") : [], vocab);
  if (!concepts.length) throw new Error("concepts must be 1-3 tags from the language card's Concept tags list");
  const title = text(o, "title").trim().slice(0, 60);
  return { title, task: text(o, "task"), requirements, examples: text(o, "examples"), concepts: concepts.slice(0, 3), stub: text(o, "stub"), tests };
}

export function nextExamId(root: string, title: string): string {
  let n = 0;
  try { for (const d of readdirSync(join(root, "exam"))) n = Math.max(n, Number(/^(\d+)-/.exec(d)?.[1] ?? 0)); } catch { /* no exam/ yet */ }
  return `${String(n + 1).padStart(2, "0")}-${slugify(title).slice(0, 24).replace(/-+$/, "")}`;
}

export interface Made { id: string; dir: string; spec: ExamSpec }

/** Remove the files this call wrote, then its now-empty folders (like writeScaffold, M4 #26). */
function unwrite(paths: string[], root: string, dir: string) {
  for (const p of paths.reverse()) rmSync(p, { force: true });
  for (const d of [join(root, dir, "src"), join(root, dir, "tests"), join(root, dir), join(root, "exam")]) {
    try { if (existsSync(d)) rmdirSync(d); } catch { /* not empty: keep */ }
  }
}

export async function makeExam(d: { complete: Complete; exec: RunExec; system: string; prompt: string; language: string; root: string; vocab: Vocab | null; size: ExamSize; topic: string | null }): Promise<Made> {
  let reason = "";
  for (let attempt = 0; attempt < 2; attempt++) {
    const user = attempt === 0 ? d.prompt : `${d.prompt}\n\nYour previous exam was rejected: ${reason}. Reply with only the corrected JSON object.`;
    const spec = await completeJson(d.complete, d.system, user, (v) => checkExam(v, d.vocab));
    const id = nextExamId(d.root, spec.title);
    const dir = `exam/${id}`;
    const files: [string, string][] = [...examFiles(d.language, spec.stub, spec.tests), ["brief.md", renderBrief(spec, { id, language: d.language, size: d.size, minutes: LIMIT_MIN[d.size], topic: d.topic })]];
    const written: string[] = [];
    try {
      for (const [rel, t] of files) written.push(writeInRoot(d.root, `${dir}/${rel}`, t, { exclusive: true }));
      const r = await runExamTests(d.exec, d.language, join(d.root, dir));
      if (r.killed) reason = "the example tests did not finish within 120 s against the stub";
      else if (r.broken) reason = `the example tests do not compile or load: ${r.out.slice(-1500)}`;
      else if (r.code === 0) reason = "the example tests pass against the stub; they must fail until the learner writes the solution";
      else return { id, dir, spec };
    } catch (e) {
      unwrite(written, d.root, dir);
      throw e;
    }
    unwrite(written, d.root, dir);
  }
  throw new Error(`exam rejected twice: ${reason}`);
}
```

```ts
  const lay = layout(language)!;
  const ours = new Set(["brief.md", "grade.md", lay.tests, ...lay.extras.map(([p]) => p), "Cargo.lock", "go.sum"]);
  const root = realpathSync(dir);
  const out: LearnerFile[] = [];
  const walk = (d: string, depth: number) => {
    for (const name of readdirSync(d).sort()) {
      if (out.length >= MAX_FILES) return;
      const abs = join(d, name), rel = relative(root, abs).split(sep).join("/");
      const st = lstatSync(abs);
      if (st.isSymbolicLink()) continue;
      if (st.isDirectory()) { if (!SKIP_DIRS.has(name) && depth < 3) walk(abs, depth + 1); continue; }
      if (!st.isFile() || ours.has(rel) || st.size > MAX_BYTES) continue;
      const text = readFileSync(abs, "utf8");
      if (text.includes("\0")) continue;
      out.push({ rel, lines: text.split(/\r?\n/).slice(0, MAX_LINES) });
    }
  };
  walk(root, 0);
  return out;
}

const EVIDENCE = /^([\w./-]+):(\d+)\b/;

function evidenceOk(ev: unknown, files: LearnerFile[]): string {
  if (typeof ev !== "string") throw new Error("every evidence must be a string starting with file:line");
  const m = EVIDENCE.exec(ev.trim());
  const f = m && files.find((x) => x.rel === m[1]);
  if (!m || !f || Number(m[2]) < 1 || Number(m[2]) > f.lines.length) throw new Error(`${m ? `${m[1]}:${m[2]}` : ev} is not a line in the files you were given`);
  return ev.trim();
}

export function checkGrade(v: unknown, c: { ids: string[]; files: LearnerFile[]; testsPassed: boolean }): Grade {
  if (typeof v !== "object" || v === null) throw new Error("reply must be a JSON object");
  const o = v as Record<string, unknown>;
  const reqs = Array.isArray(o.requirements) ? o.requirements as Record<string, unknown>[] : [];
  if (reqs.map((r) => r?.id).join(",") !== c.ids.join(",")) throw new Error(`requirements must be exactly ${c.ids.join(", ")} in order`);
  const requirements = reqs.map((r) => ({ id: String(r.id), met: r.met === true, evidence: evidenceOk(r.evidence, c.files) }));
  if (!c.testsPassed && requirements.every((r) => r.met)) throw new Error("the example tests fail, so at least one requirement is not met");
  const idioms = (Array.isArray(o.idioms) ? o.idioms as Record<string, unknown>[] : []).slice(0, 5)
    .map((i) => ({ ok: i.ok === true, note: String(i.note ?? "").trim(), evidence: evidenceOk(i.evidence, c.files) }));
  const fixes = Array.isArray(o.next_fixes) ? o.next_fixes.filter((f): f is string => typeof f === "string" && !!f.trim()) : [];
  if (fixes.length !== 3) throw new Error("next_fixes must be exactly three sentences");
  const inShort = typeof o.in_short === "string" ? o.in_short.trim() : "";
  if (!inShort) throw new Error("in_short must be a non-empty string");
  return { requirements, idioms, next_fixes: fixes.map((f) => f.trim()), in_short: inShort };
}

export function score(g: Grade): number {
  const met = g.requirements.filter((r) => r.met).length / g.requirements.length;
  const idioms = g.idioms.length ? g.idioms.filter((i) => i.ok).length / g.idioms.length : 1;
  return Math.round(80 * met + 20 * idioms);
}

function testLine(t: TestRun): string {
  return t.killed ? "The example tests timed out after 120 s (an endless loop or a very slow solution)."
    : t.code === 0 ? "The example tests passed." : `The example tests failed (exit ${t.code}).`;
}

export function gradePrompt(i: { brief: string; files: LearnerFile[]; test: TestRun; checklist: string; minutes: number; limit: number }): string {
  const numbered = i.files.map((f) => `--- ${f.rel}\n${f.lines.map((l, n) => `${String(n + 1).padStart(4)}  ${l}`).join("\n")}`).join("\n\n");
  return [
    "## Brief", i.brief.trim(), "",
    "## Learner's files (numbered)", numbered || "(no files)", "",
    "## Example test run", testLine(i.test), i.test.out.slice(-4000), "",
    `## Time\n${i.minutes} of ${i.limit} minutes`, "",
    "## Language card checklist", i.checklist.trim(),
  ].join("\n");
}

export function renderGrade(g: Grade, m: { id: string; score: number; minutes: number; limit: number; test: TestRun }): string {
  const late = m.minutes > m.limit;
  return [
    `# Grade: exam ${m.id}`, "",
    `**${m.score}/100** · ${m.minutes} of ${m.limit} minutes · ${late ? "late" : "on time"}`, "",
    "## Requirements", "", ...g.requirements.map((r) => `- ${r.met ? "✔" : "✘"} **${r.id}** ${r.evidence}`), "",
    ...(g.idioms.length ? ["## Idioms", "", ...g.idioms.map((i) => `- ${i.ok ? "✔" : "✘"} ${i.note} (${i.evidence})`), ""] : []),
    "## Example tests", "", testLine(m.test), ...(m.test.out ? ["", "```", m.test.out.split("\n").slice(-30).join("\n"), "```"] : []), "",
    "## Next fixes", "", ...g.next_fixes.map((f, n) => `${n + 1}. ${f}`), "",
    "## In short", "", g.in_short, "",
  ].join("\n");
}
```

```ts
import { bandFor } from "./policy.js";
import type { EpisodeRecord, ExamRecord } from "./profile.js";
import { remapConcepts, type Vocab } from "./packs.js";

// /tutor-progress (spec 2026-10-13 §6, gap #8): exam trend, hint use over time, concept map. Lines ≤ 40 columns.
const SPARK = ["▁", "▃", "▅", "▇", "█"];
const W = 40;
const avg = (xs: number[]) => Math.round((xs.reduce((a, b) => a + b, 0) / xs.length) * 10) / 10;

/** "label: a, b, c" wrapped at W with a two-space hanging indent. */
function wrapList(label: string, items: string[]): string[] {
  const out: string[] = [];
  let line = `${label}:`;
  for (const it of items) {
    const next = `${line}${line.endsWith(":") ? " " : ", "}${it}`;
    if (Array.from(next).length > W && !line.endsWith(":")) { out.push(`${line},`); line = `  ${it}`; } else line = next;
  }
  out.push(line);
  return out;
}

export function progressReport(i: { language: string; level: number | null; episodes: EpisodeRecord[]; exams: ExamRecord[]; concepts: { language: string; tag: string; ease: number; episodes: number }[]; vocab: Vocab | null }): string {
  const lines = [`**${i.language}**${i.level === null ? "" : ` · level ${i.level} (${bandFor(i.level)})`}`, ""];
  if (!i.episodes.length && !i.exams.length) return [...lines, "no episodes or exams yet"].join("\n");
  const recent = i.episodes.slice(-20).map((e) => e.rungs_used);
  if (recent.length) {
    lines.push("Hints per episode, oldest → newest:", `\`${recent.map((r) => SPARK[Math.min(Math.max(r, 1), 5) - 1]).join("")}\``);
    const half = Math.floor(recent.length / 2);
    lines.push(recent.length >= 4 ? `hint levels used: ${avg(recent.slice(0, half))} → ${avg(recent.slice(half))}` : `hint levels used: ${avg(recent)}`, "");
  }
  if (i.exams.length) {
    lines.push("Exams:", ...i.exams.slice(-5).map((e) => `- ${e.exam.slice(0, 18)} ${e.score} · ${e.minutes} min${e.late ? " · late" : ""}`));
    if (i.exams.length >= 2) lines.push(`trend: ${i.exams.slice(-5).map((e) => e.score).join(" → ")}`);
    lines.push("");
  }
  const cs = remapConcepts(i.concepts, i.vocab);
  const by = (lo: number, hi: number) => cs.filter((c) => c.ease >= lo && c.ease < hi).sort((a, b) => b.ease - a.ease).map((c) => c.tag);
  if (cs.length) lines.push("Concepts:", ...wrapList("strong", by(0.7, 1.01)), ...wrapList("shaky", by(0.4, 0.7)), ...wrapList("weak", by(0, 0.4)));
  return lines.join("\n").trimEnd();
}
```
