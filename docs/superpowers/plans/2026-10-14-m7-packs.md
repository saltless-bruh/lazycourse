# M7 Language Packs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every tutor turn knows the project's language as installed. It gets a short language card (version, project constraint, conventions, pitfalls, concept tags), and the tutor has cookbook and expert skills to load. Concept tags in judgments use one vocabulary. An editor pack teaches LazyVim itself. The learner can show or hide the model's thinking, and by default it is hidden only at the pro band.

**Architecture:** Packs are data: `pi-tutor/packs/<lang>/card.md`, with the card text plus a `## Concept tags` list. New pure modules parse them (`packs.ts`), read project constraints (`knowledge/constraints.ts`) and render the card with a live header (`card.ts`). `index.ts` puts the rendered card into a `tutor_lang` system-prompt section each turn. Tags are normalized in `applyTurnJudgment`, and thinking is hidden through the existing `registerMarkdownTransformer`. Cookbooks and expert skills are bundled skills under `pi-tutor/skills/`. A script runs every cookbook example with the installed toolchains.

**Tech Stack:** TypeScript (Node 26, `node:sqlite`), vitest, Pi 1.1.0 extension API, Lua/plenary for the Neovim command, Markdown skills (Agent Skills format).

**Spec:** `docs/superpowers/specs/2026-10-13-tutor-roles-packs-exams-design.md` §5 (packs), §5.1 (versions), §5.3 (expert skills), §5.4 (loading), §7 gap #2 (budget), §8 (files), §9 M7 row, §10 (upstream drift).

## Review Focus

1. **A language with no pack.** Example: the learner picked "c" through "Other" in `/tutor-start`. The turn gets only the editor card. Tags are normalized but not filtered, and nothing throws (Task 4, Task 5 tests).
2. **A toolchain that is missing or hangs.** The card says "not installed", the turn waits at most once per language and root (cached), and a hang costs at most 6 s, once (Task 3 test with a never-resolving exec plus fake timers).
3. **Malformed constraint files.** A broken `pyproject.toml`, `package.json` that is not JSON, or an empty `go.mod` means the constraint is left out and nothing throws (Task 3 tests).
4. **The language changes mid-session.** Outside a project, the editor's filetype moves from `.py` to `.lua`, and the next turn's card follows (Task 4 test).
5. **The thinking toggle in odd states.** It is set while a reply streams, after `/new` or a resume, after a Pi restart (the profile keeps it), and in print mode, which has no transformer calls. Pi's own global "hide thinking" setting still wins (Task 1 tests).

```ts
// Show or hide the model's thinking in the tutor pane (learner request 2026-10-14): display only,
// the model still thinks and the session keeps it. `auto` hides it only at the pro band.
export type ThinkingMode = "auto" | "show" | "hide";
const MODES: readonly ThinkingMode[] = ["auto", "show", "hide"];
export const THINKING_LABEL = "thinking hidden · /tutor-thinking show";

export function parseThinkingMode(s: string): ThinkingMode | null {
  const m = s.trim().toLowerCase();
  return (MODES as readonly string[]).includes(m) ? (m as ThinkingMode) : null;
}

export function thinkingHidden(mode: ThinkingMode, band: Band): boolean {
  return mode === "hide" || (mode === "auto" && band === "pro");
}
```

```ts
import { existsSync, readFileSync } from "node:fs";
import { fileURLToPath } from "node:url";
import { dirname, join } from "node:path";

// Language packs (spec 2026-10-13 §5, §5.4): pi-tutor/packs/<lang>/card.md holds the always-on card
// and the controlled concept-tag vocabulary the judgment block may use (gap #5).
const DIR = join(dirname(fileURLToPath(import.meta.url)), "..", "..", "packs");

export interface Tag { tag: string; meaning: string; aliases: string[] }
export interface Pack { language: string; body: string; tags: Tag[] }
export type Vocab = Map<string, string>;

const TAGS_HEADING = /^## Concept tags[ \t]*$/m;
const TAG_LINE = /^- `([^`]+)`:\s*(.*?)(?:\s*\(aliases:\s*([^)]*)\))?\s*$/;

export function normalizeTag(s: string): string {
  return s.trim().toLowerCase().replace(/[\s_]+/g, "-");
}

export function parsePack(language: string, text: string): Pack {
  const m = TAGS_HEADING.exec(text);
  const body = (m ? text.slice(0, m.index) : text).trim();
  const tags: Tag[] = [];
  if (m) for (const line of text.slice(m.index + m[0].length).split(/\r?\n/)) {
    const t = TAG_LINE.exec(line.trim());
    if (t) tags.push({ tag: normalizeTag(t[1]), meaning: t[2].trim(), aliases: t[3] ? t[3].split(",").map(normalizeTag).filter(Boolean) : [] });
  }
  return { language, body, tags };
}

const cache = new Map<string, Pack | null>();

export function loadPack(language: string): Pack | null {
  if (!cache.has(language)) {
    const f = join(DIR, language, "card.md");
    cache.set(language, /^[a-z0-9-]+$/.test(language) && existsSync(f) ? parsePack(language, readFileSync(f, "utf8")) : null);
  }
  return cache.get(language)!;
}

export function vocabOf(...packs: (Pack | null)[]): Vocab | null {
  const v: Vocab = new Map();
  for (const p of packs) for (const t of p?.tags ?? []) {
    if (!v.has(t.tag)) v.set(t.tag, t.tag);
  }
  for (const p of packs) for (const t of p?.tags ?? []) for (const a of t.aliases) if (!v.has(a)) v.set(a, t.tag);
  return v.size ? v : null;
}

/** Judgment tags in the pack's vocabulary: aliases mapped, unknown dropped; no vocabulary → only normalized. */
export function normalizeTags(tags: string[], vocab: Vocab | null): string[] {
  const out: string[] = [];
  for (const raw of tags) {
    const n = normalizeTag(raw);
    const t = vocab ? vocab.get(n) : n || undefined;
    if (t && !out.includes(t)) out.push(t);
  }
  return out;
}
```

Note the merge order in `vocabOf`: all real tags go in first, then aliases. An alias in one pack therefore never shadows a real tag in another, which is what the "first pack wins a clash" test expects.

```ts
import { readdirSync, readFileSync } from "node:fs";
import { join } from "node:path";

// Project constraints read from files (spec 2026-10-13 §5.1); the card states them next to the
// installed version. Line-level reads: a broken file gives null, never an exception.
function read(root: string, file: string): string | null {
  try { return readFileSync(join(root, file), "utf8"); } catch { return null; }
}
const tomlKey = (text: string, key: string) => new RegExp(`^\\s*${key}\\s*=\\s*"([^"]+)"`, "m").exec(text)?.[1] ?? null;

export function readConstraint(language: string, root: string): string | null {
  try {
    switch (language) {
      case "python": {
        const t = read(root, "pyproject.toml"); const v = t && tomlKey(t, "requires-python");
        return v ? `requires-python ${v} (pyproject.toml)` : null;
      }
      case "rust": {
        const t = read(root, "Cargo.toml"); if (!t) return null;
        const parts = [tomlKey(t, "edition") && `edition ${tomlKey(t, "edition")}`, tomlKey(t, "rust-version") && `rust-version ${tomlKey(t, "rust-version")}`].filter(Boolean);
        return parts.length ? `${parts.join(", ")} (Cargo.toml)` : null;
      }
      case "go": {
        const v = /^go\s+(\d+\.\d+(?:\.\d+)?)\s*$/m.exec(read(root, "go.mod") ?? "")?.[1];
        return v ? `go ${v} (go.mod)` : null;
      }
      case "typescript": {
        const t = read(root, "package.json"); if (!t) return null;
        const j = JSON.parse(t) as { engines?: { node?: string }; devDependencies?: Record<string, string>; dependencies?: Record<string, string> };
        const ts = j.devDependencies?.typescript ?? j.dependencies?.typescript;
        const parts = [j.engines?.node && `node ${j.engines.node}`, ts && `typescript ${ts}`].filter(Boolean);
        return parts.length ? `${parts.join(", ")} (package.json)` : null;
      }
      case "lua": {
        const f = readdirSync(root).find((n) => n.endsWith(".rockspec")); if (!f) return null;
        const v = /"(lua\s*[<>=~]+\s*[\d.]+)"/.exec(read(root, f) ?? "")?.[1];
        return v ? `${v} (${f})` : null;
      }
      default: return null;
    }
  } catch { return null; }
}
```

```ts
import { readConstraint } from "./constraints.js";

export interface Toolchain { installed: string | null; runtime: string | null; constraint: string | null }

/** What the card states (spec §5.1): the compiler/interpreter version, a runtime fallback, the project's constraint. */
export async function toolchain(language: string, root: string, rawExec: Exec): Promise<Toolchain> {
  const spec = LANGS[language];
  if (!spec) return { installed: null, runtime: null, constraint: null };
  // pi.exec enforces `timeout`, but a turn must never wait on an exec that ignores it (Review Focus #2).
  const exec: Exec = (c, a, o) => {
    let t: ReturnType<typeof setTimeout> | undefined;
    const limit = new Promise<never>((_, rej) => { t = setTimeout(() => rej(new Error("version command timed out")), 6000); });
    return Promise.race([rawExec(c, a, o), limit]).finally(() => clearTimeout(t));
  };
  const installed = await detectVersion(language, exec);
  let runtime: string | null = null;
  if (!installed && spec.runtime) {
    try {
      const r = await exec(spec.runtime.command, spec.runtime.args, { timeout: 5000 });
      const v = r.code === 0 ? parseVersion(`${r.stdout}\n${r.stderr}`) : null;
      runtime = v ? `${spec.runtime.name} ${v}` : null;
    } catch { runtime = null; }
  }
  return { installed, runtime, constraint: readConstraint(language, root) };
}
```

```ts
import type { Pack } from "./packs.js";
import type { Toolchain } from "./knowledge/versions.js";
import type { RefMeta } from "./knowledge/reference.js";

// The always-on language card (spec 2026-10-13 §5): live header (version, constraint, reference,
// skills, other languages the learner knows) + the pack body + its concept tags. ≤ 600 tokens (gap #2).
export interface CardInfo { tc: Toolchain; ref: RefMeta | null; knows: string[]; skills: string[] }

const NAMES: Record<string, string> = { python: "Python", rust: "Rust", go: "Go", typescript: "TypeScript", lua: "Lua" };
const SKILL_ROLE: Record<string, string> = { cookbook: "plain step → idiom", expert: "patterns, pitfalls, review" };
const majorMinor = (v: string) => /^(\d+\.\d+)/.exec(v)?.[1] ?? v;

const tagLine = (p: Pack) => (p.tags.length ? `Tags: ${p.tags.map((t) => `\`${t.tag}\` ${t.meaning}`).join(" · ")}` : "");

export function renderCard(pack: Pack, info: CardInfo): string {
  const lang = pack.language, name = NAMES[lang] ?? lang;
  const { installed, runtime, constraint } = info.tc;
  const have = installed ? `${name} ${installed}` : runtime ? `${lang === "typescript" ? "tsc" : name} not installed · runtime ${runtime}` : "not installed (from the language's version command)";
  const lines = [`[language card: ${lang}]`, `Installed: ${have}${constraint ? ` · project: ${constraint}` : ""}`];
  if (info.ref) {
    const refVer = /~(\d+\.\d+)/.exec(info.ref.slug)?.[1] ?? info.ref.release;
    let r = `Reference: \`tutor-${lang}-ref\` for ${info.ref.slug}; cite it.`;
    if (installed && refVer && majorMinor(refVer) !== majorMinor(installed)) r += ` The reference is for ${majorMinor(refVer)} but ${majorMinor(installed)} is installed: say so when it matters.`;
    lines.push(r);
  } else lines.push(`Reference: none yet; suggest \`:TutorDocs ${lang}\`.`);
  const skills = info.skills.map((s) => `\`${s}\` (${SKILL_ROLE[s.split("-").at(-1) ?? ""] ?? "see its description"})`);
  if (skills.length) lines.push(`Skills: ${skills.join(", ")}`);
  const knows = info.knows.filter((l) => l !== lang);
  if (knows.length) lines.push(`Learner also knows: ${knows.join(", ")}. Use the cookbook's Bridge lines.`);
  if (pack.tags.length) lines.push("Concept tags: use only the tags listed below in the judgment block.");
  return [...lines, pack.body, tagLine(pack)].filter(Boolean).join("\n");
}

export function renderEditorCard(pack: Pack): string {
  return ["[editor card: LazyVim]", pack.body, tagLine(pack)].filter(Boolean).join("\n");
}
```

```js
#!/usr/bin/env node
// Runs every cookbook example with the toolchains installed here (`npm run cookbooks`; not part of
// `npm test`). Each example must run with no arguments and exit 0. A missing toolchain is a skip.
import { execFileSync, spawnSync } from "node:child_process";
import { mkdtempSync, readFileSync, writeFileSync, existsSync } from "node:fs";
import { tmpdir } from "node:os";
import { join, dirname } from "node:path";
import { fileURLToPath } from "node:url";

const SKILLS = join(dirname(fileURLToPath(import.meta.url)), "..", "skills");
const has = (cmd, args) => spawnSync(cmd, args, { stdio: "ignore" }).status === 0;
const RUN = {
  python: { tag: "python", ok: () => has("python3", ["--version"]), run: (d, src) => { const f = join(d, "x.py"); writeFileSync(f, src); return ["python3", [f], d]; } },
  lua: { tag: "lua", ok: () => has("lua", ["-v"]), run: (d, src) => { const f = join(d, "x.lua"); writeFileSync(f, src); return ["lua", [f], d]; } },
  typescript: { tag: "ts", ok: () => has("node", ["--version"]), run: (d, src) => { const f = join(d, "x.ts"); writeFileSync(f, src); return ["node", [f], d]; } },
  go: { tag: "go", ok: () => has("go", ["version"]), run: (d, src) => {
    writeFileSync(join(d, "go.mod"), "module x\n\ngo 1.22\n");
    if (/func Test\w*\(t \*testing\.T\)/.test(src)) { writeFileSync(join(d, "x_test.go"), src); return ["go", ["test", "./..."], d]; }
    writeFileSync(join(d, "main.go"), src); return ["go", ["run", "."], d]; } },
  rust: { tag: "rust", ok: () => has("rustc", ["--version"]), run: (d, src) => {
    const f = join(d, "x.rs"); writeFileSync(f, src);
    const test = src.includes("#[cfg(test)]");
    execFileSync("rustc", ["--edition", "2024", ...(test ? ["--test"] : []), "-o", join(d, "x"), f], { stdio: "pipe" });
    return [join(d, "x"), [], d]; } },
};

let failed = 0, ran = 0;
for (const [lang, r] of Object.entries(RUN)) {
  const file = join(SKILLS, `tutor-${lang}-cookbook`, "SKILL.md");
  if (!existsSync(file)) continue;
  if (!r.ok()) { process.stdout.write(`skip ${lang}: toolchain not installed\n`); continue; }
  const text = readFileSync(file, "utf8");
  for (const sec of text.split(/^## /m).slice(1)) {
    const id = sec.split(":")[0].trim();
    const m = new RegExp("```" + r.tag + "\\n([\\s\\S]*?)\\n```").exec(sec);
    if (!m) continue;
    const d = mkdtempSync(join(tmpdir(), `cb-${lang}-`));
    try {
      const [cmd, args, cwd] = r.run(d, m[1] + "\n");
      const p = spawnSync(cmd, args, { cwd, encoding: "utf8", timeout: 60_000, env: { ...process.env, TMPDIR: d } });
      ran++;
      if (p.status !== 0) { failed++; process.stdout.write(`FAIL ${lang} ${id}\n${p.stdout}${p.stderr}\n`); }
    } catch (e) { failed++; ran++; process.stdout.write(`FAIL ${lang} ${id}\n${e.stderr ?? e.message}\n`); }
  }
}
process.stdout.write(`${ran - failed}/${ran} cookbook examples ran\n`);
process.exit(failed ? 1 : 0);
```

```js
#!/usr/bin/env node
// Spec §10: adapted skills drift from upstream. Compares each adapted skill's references/ and the
// recorded upstream version with a fullstack-dev-skills checkout (`npm run upstream-diff [path]`).
import { readFileSync, readdirSync, existsSync } from "node:fs";
import { join, dirname } from "node:path";
import { homedir } from "node:os";
import { fileURLToPath } from "node:url";

const SKILLS = join(dirname(fileURLToPath(import.meta.url)), "..", "skills");
const UP = process.argv[2] ?? join(homedir(), ".claude/plugins/marketplaces/fullstack-dev-skills");
if (!existsSync(join(UP, "version.json"))) { process.stdout.write(`no upstream checkout at ${UP}\n`); process.exit(2); }
const upVersion = JSON.parse(readFileSync(join(UP, "version.json"), "utf8")).version;
let drift = 0;
for (const d of readdirSync(SKILLS).filter((n) => /^tutor-.+-expert$/.test(n))) {
  const m = /^upstream: fullstack-dev-skills\/([\w-]+)@([\d.]+)/m.exec(readFileSync(join(SKILLS, d, "SKILL.md"), "utf8"));
  if (!m) continue;
  const [, skill, ours] = m;
  if (ours !== upVersion) { drift++; process.stdout.write(`${d}: recorded ${ours}, upstream now ${upVersion}\n`); }
  const refs = join(UP, "skills", skill, "references");
  for (const f of readdirSync(refs)) {
    const mine = join(SKILLS, d, "references", f);
    if (!existsSync(mine)) { drift++; process.stdout.write(`${d}: new upstream reference ${f}\n`); continue; }
    if (readFileSync(mine, "utf8") !== readFileSync(join(refs, f), "utf8")) { drift++; process.stdout.write(`${d}: ${f} differs\n`); }
  }
}
process.stdout.write(drift ? `${drift} difference(s)\n` : "adapted skills match upstream\n");
process.exit(drift ? 1 : 0);
```
