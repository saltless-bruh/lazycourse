# Editor card (LazyVim 16)

- Leader is Space; press it and wait for the which-key menu.
- Files: `<leader><space>` find file, `<leader>/` grep, `<leader>e` explorer, `<S-h>`/`<S-l>` buffers.
- Code (needs a language server): `gd` definition, `gr` references, `K` hover, `<leader>ca` fix, `<leader>cr` rename.
- Errors: `]d`/`[d` next/previous, `<leader>cd` line detail, `<leader>xx` list.
- Windows: `<C-h/j/k/l>` move, `<leader>-`/`<leader>|` split.
- Tutor: `<leader>tt` pane, `<leader>tr` run, `:TutorLevel`, `:TutorPlan`; `<C-\><C-n>` leaves its terminal.
- Basics: `:w` save, `u` undo, `<C-r>` redo, `<Esc>` normal mode.

## Concept tags
- `motions`: moving the cursor (aliases: movement, navigation)
- `editing`: insert, change, delete (aliases: insert-mode, text-editing)
- `modes`: normal, insert, visual (aliases: mode, normal-mode, visual-mode)
- `search`: find, grep (aliases: grep, find)
- `files`: open, save (aliases: file, save, open-file)
- `explorer`: file tree (aliases: file-tree, neo-tree)
- `windows`: splits (aliases: splits, split)
- `buffers`: buffers (aliases: buffer)
- `lsp-navigation`: definition, references (aliases: go-to-definition, lsp, references)
- `diagnostics`: errors, warnings (aliases: diagnostic, errors-list, trouble)
- `code-actions`: fixes, rename (aliases: code-action, rename, refactor)
- `terminal`: terminal mode (aliases: terminal-mode)
- `tutor-commands`: :Tutor commands (aliases: tutor)
- `undo`: undo, redo (aliases: redo)
